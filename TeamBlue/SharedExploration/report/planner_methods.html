Zymera · T5 · The L2 planner — method + Phase-2 ablation

A learned value-propagation planner for connectivity-constrained cooperative coverage

The whole story of the L2 planner: the mission and architecture it lives in, why reinforcement learning can't train it, the distillation fix, its mission results, and the four-architecture ablation.

MAPPO-CTDE · soft connectivity (no hard mask) · distilled @ 32×32, 4000 steps · size-invariant · merges the earlier MVProp method note · 2026-08

Result. The three value-iteration planners (MVProp, Highway-VIN, GPPN) are identical at the ceiling — 100% reach, ~99% optimal-move on every unseen map — so the extra gating machinery buys nothing over plain MVProp. The transformer (MSP) fails: 59.5% reach despite low distill-error, because attention without the value-iteration recurrence learns local values but not a globally navigable field. The VI recurrence is the load-bearing inductive bias, and a 332-byte MVProp beats a 78 KB transformer. Winner into Phase 3: MVProp + distillation (already the keeper — nothing improves it).

1Setting & architecture

A team of N agents performs cooperative coverage on a grid under partial observability, communicating only over a limited-range, time-varying graph — a finite-horizon cooperative Dec-POMDP. Connectivity is a hard mission constraint: breaking the comm graph is a failure, not merely a lower reward, so we grade connectivity-first (fraction of steps with algebraic connectivity λ2 > 0.5). The policy is a learned perception–action–communication backbone (per-agent CNN → GNN over neighbours) feeding a three-level action stack: L3 a goal head picks a waypoint from a stride-3 compass stencil → L2 the planner floods a value field to it → L1 reads one env-valid move off that field. Training is MAPPO–CTDE with a count-invariant central critic; connectivity is enforced softly (Lagrangian dual, no hard mask — the graph stays breakable, which the resilience study requires). The weak link was the reactive L1 move head: it cannot route around obstacles on unseen maps (≈25% zero-shot coverage vs a classical planner's 78.9%). This report is about the L2 planner that replaces it.

2Why RL can't train the planner, and the distillation fix

Trained end-to-end by policy gradient, a from-scratch MVProp collapses to ~21% on open terrain. The cause is structural: at init the passability conv outputs ≈0 so w = σ(0) = ½; the flood decays by γw ≈ γ/2 per cell and dies within ~5 cells. The field is flat where the agents actually are, so the five move-scores at a far corner probe to [0,0,0,0,0] and the gradient through the K max-propagation sweeps vanishes.

The fix is dense supervision: for random (walls, goal) samples the 4-connected geodesic wavefront gives the exact γdistance field; the planner learns to reproduce it, so its argmax-value move equals the shortest-path move. The teacher runs only at training time — at inference the planner is pure learned MVProp (no classical code executes), so the system stays fully learned. Integration is a one-variable swap: the frozen distilled planner replaces the greedy L1 controller and the RL loss never touches it (the move is a deterministic readout during collection), so everything else — the CTDE critic, the connectivity stack — is byte-identical to the reactive baseline.

5MVPropkeeper

Why

Max-propagation Value/Value-Propagation network (Nardelli 2018). A per-cell value floods from the goal, discounted per step and blocked by walls; the neighbour values are the move scores — differentiable, size-invariant, and a drop-in for the classical wavefront. The default L2 planner.

Math

V0 = r  ·  Vk+1(x) = max( r(x), γ·w(x)·max4-nbr Vk(x) )
r = goal one-hot (anchored spike)  ·  w = σ( conv(map) + binit )  ·  only w is learned

Two structural fixes make it trainable (the probe_mvprop finding): anchor r to the goal one-hot (the flood always originates strongly), and flood-far-at-init via binit=2 so w≈0.88 before training (else w=σ(0)=0.5 → flood dies in ~5 cells → dead flat field → vanishing gradient).

Code

def propagate(r, w, K, gamma=0.9):
    def step(V, _):
        return jnp.maximum(r, gamma * w * _max_4nbr(V)), None
    V, _ = jax.lax.scan(step, r, None, length=K); return V

def field(self, x):
    r = x[self.goal_ch]                        # anchored goal spike
    w = jax.nn.sigmoid(self.gain_conv(x)[0])   # learned passability (b_init=2)
    return propagate(r, w, self.K, self.gamma)

Experiments

100% reach / 99% optimal-move across all 8 unseen map types; 332 bytes (only a 3×3 passability conv is learned — the recurrence is a fixed operator). RL-only from the unfixed config is dead (flat field); with the anchor+bias fix the init field is already a usable γdist gradient, and distillation drives it to route.

6Highway-VINmandatory control

Why

Highway Value Iteration Networks (Wang et al., ICML 2024) add a per-cell highway carry gate across value-iteration sweeps — the published fix for the vanishing gradient that kills deep value iteration. The decisive control: does the architectural fix remove the need to distill (does RL-only now train)?

Math

Vk+1 = g · max(r, γ·w·max4Vk) + (1−g) · Vk  ·  g = σ(conv(map))
the (1−g)·Vk term is a gradient highway across the K sweeps

Code

def field(self, x):
    r = x[self.goal_ch]
    w = jax.nn.sigmoid(self.gain_conv(x)[0])
    g = jax.nn.sigmoid(self.gate_conv(x)[0])           # highway update gate
    def step(V, _):
        newV = jnp.maximum(r, self.gamma * w * _max_4nbr(V))
        return g * newV + (1.0 - g) * V, None            # highway carry
    V, _ = jax.lax.scan(step, r, None, length=self.K); return V

Experiments

Ties MVProp exactly — 100% reach, 99% optimal, distill-MSE 2.0e−4, 664 bytes. Its init gradient (3.4e−2) is non-vanishing, so RL-only is viable-at-init — but so is fixed MVProp (4.6e−2). The honest conclusion: the anchor+bias fix already removes the init-flatness for all the VI planners, so Highway confers no advantage here. A decisive "distillation required vs Highway rescues RL-only" claim needs a full RL-only convergence run (not attempted); at the distillation level, Highway is a no-op over MVProp.

7GPPN

Why

Gated Path Planning Networks (Lee et al., NeurIPS 2018) replace VIN's hard max with a data-dependent (LSTM/GRU-style) update gate computed each sweep from the recurrent state — for stable long-horizon credit propagation. Tests whether learned gating beats the fixed max.

Math

cand = max(r, γ·w·max4Vk)  ·  z = σ( conv([ Vk, cand, γw·nbr ]) )
Vk+1 = z · cand + (1−z) · Vk  ·  gate depends on the current field (vs Highway's map-only gate)

Code

def field(self, x):
    r = x[self.goal_ch]; w = jax.nn.sigmoid(self.gain_conv(x)[0])
    def step(V, _):
        nbr = _max_4nbr(V); cand = jnp.maximum(r, self.gamma * w * nbr)
        feat = jnp.stack([V, cand, self.gamma * w * nbr])   # recurrent features
        z = jax.nn.sigmoid(self.gate_conv(feat)[0])         # data-dependent gate
        return z * cand + (1.0 - z) * V, None
    V, _ = jax.lax.scan(step, r, None, length=self.K); return V

Experiments

Also ties MVProp — 100% reach, 99% optimal, 700 bytes. The learned data-dependent gate neither helps nor hurts over the fixed max: once distilled against the exact wavefront, all three VI variants converge to the same geodesic field. Gating is a solution to a training problem the distillation target already solves.

8MSP — spatial transformerfails

Why

A compact spatial-planning transformer: axial self-attention over grid rows/columns (size-invariant, O(HW·(H+W)) not O((HW)²)) with sinusoidal 2-D positional encoding predicts the value field directly — no value-iteration recurrence. Tests whether attention can learn to route in place of VI.

Math

z0 = embed(cell feat) + PE2D  ·  z = z + AxialAttn(z)  ·  z = z + MLP(z)  (×2)
V = σ(head(z))  ·  no recurrence — the field is a single forward pass

Code

def field(self, x):
    C, H, W = x.shape
    z = embed(x) + _sincos_pe(H, W, d)         # (H,W,d) tokens + 2-D PE
    z = z + _axial_attn(z, q1, k1, v1); z = z + mlp1(z)  # attend rows then cols
    z = z + _axial_attn(z, q2, k2, v2); z = z + mlp2(z)
    return jax.nn.sigmoid(head(z))[..., 0]     # (H,W) value field

Experiments

Fails to generalize: 59.5% reach (open 96 → rooms 37, corridors 39, random 48) — it collapses exactly on maps needing long-range routing. Yet optimal-move is 92.5% and distill-MSE is low: it fits per-cell values well but its field is not globally monotone to the goal, so following it hits local maxima and traps. At 78 KB it is 236× larger than MVProp and worse. Caveat: this is a compact 2-layer axial MSP at a matched 4000-step budget — not proof that no transformer can plan, but a strong signal that at matched budget/size the VI recurrence's guaranteed monotone descent is decisive.

9Verdict & per-map detail

Phase 2 closes with MVProp+distillation as the winner into Phase 3. The value-iteration recurrence is the load-bearing inductive bias — it guarantees a navigable (monotone-to-goal) field, which is what reach measures and what a transformer cannot supply at matched budget. Highway and GPPN confirm that once you distill against the exact wavefront, added gating is a no-op; MVProp's 332 bytes are sufficient. The one claim this doesn't settle is "distillation required" at the RL-only convergence level — the init-gradient probe shows all VI planners are viable-at-init (the anchor+bias fix, not architecture), so a full RL-only training run remains the decisive follow-up. Consistent with the positioning search: planner-generalization itself is a scooped axis (VProp/VIN/Neural-A*), so this rounds out the ablation and documents the choice rather than carrying a paper.
