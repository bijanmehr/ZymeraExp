Credit assignment & the division-of-labor fix

The finding. Coverage here is 1×1 stood-on — the cell each agent operates on (the 3×3 sensor footprint is navigation range, shown greyed as reference). The v1 default (shared credit) pays every agent the team-total new-cell count, so no agent is rewarded for reaching ground the others missed — the team floods one region and coverage stalls at 21%. Restoring exact difference credit (each agent paid only for a cell it covered alone) makes agents fan out: coverage 21 → 44%. But the price is connectivity — the team stops holding one component (one-piece 99 → 78%). Gating coverage on connectivity holds coverage (44%) but connectivity collapses (one-piece 45%).
