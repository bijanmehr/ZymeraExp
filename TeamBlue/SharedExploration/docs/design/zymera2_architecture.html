zymera2 — architecture

Companion to 2026-08-10-zymera2-world-design.md · three views: module map (the interaction overview) · walkthrough (one block per step, inputs → block → outputs) · audit sheet (may-read / must-not · guarantees G1–G14 · boundary matrix).

Module interface map. Boxes list the methods each module exposes (blue mono); arrows carry the objects that actually travel, with types. Solid = every tick · dashed = observer-only · thick = once per episode. The boundary reads directly: minds send actions: i32[N] and outboxes: PyTree down; only obs_i comes back; the bridge touches the world solely through geometry.* returns; tasks consume events and inject body_controls — never touching an agent. Full signatures and forbidden reads per module: the audit sheet tab.
